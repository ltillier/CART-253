# POV:SEAGULL

Laurel Tillier

[View this project online](https://ltillier.github.io/CART-253/topics/prototypes/03_variables/variables_prototype_01/)

## Description

This prototype uses the noise() function to add movement to a turtle on its way to the sea. This is the first of three variables prototypes done for CART 253 :P
