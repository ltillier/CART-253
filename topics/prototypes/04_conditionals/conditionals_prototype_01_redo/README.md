# CATCH THE UNICORN

Laurel Tillier

[View this project online](https://ltillier.github.io/CART-253/topics/prototypes/04_conditionals/conditionals_prototype_01_redo)

## Description

This is the first prototype for Conditionals (week 5). Use the mouse to catch the unicorn, but note that it will move away if you go too fast or stay too close.
