# HERDING SHEEP

Laurel Tillier

[View this project online](https://ltillier.github.io/CART-253/topics/prototypes/04_conditionals/conditionals_prototype_02)

## Description

This is the 2nd prototype for Conditionals. You are a herder, and your sheep have anxiety. Make sure they don't wander off the canvas! Use your mouse to herd the sheep wherever you want them to go.
